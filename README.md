# NYR
Sportegyesületi Nyilvántartó Rendszer A BME VIK Prog2 NHF keretében készülő szoftver célja az egyesületi adminisztráció digitalizálása. A program kiváltja a táblázatokat, automatizálva a bérletfigyelést és a befizetések követését a hibák minimalizálása érdekében.  Státusz: Tervezés alatt Határidő: 2026. 05. 26. Technológia: C++ (OOP)
